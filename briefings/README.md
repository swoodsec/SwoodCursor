# Daily Cyber & AI Security Briefing

Curated daily digests of high-value cybersecurity and AI security reporting.

## Format

Each day lives under `briefings/YYYY-MM-DD/`:

- `index.md` — concise bullet list with links to each summary and the original article
- one short summary file per selected story

## Selection criteria

Prefer stories that change operational priorities: actively exploited flaws, high-impact patches, ransomware/edge-device campaigns, and AI capabilities or agent-security research with clear defender implications.
